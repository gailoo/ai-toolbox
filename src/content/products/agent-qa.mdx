agent-qa 是 vostride 的应用测试工具，可通过 CLI 或 MCP 接入开发工作流，测试 Web、Android 和 iOS 应用。它结合 memidex 持久记忆与经过验证的自我改进，并保留可供复核的运行证据。

本页的「免费」指本地软件包安装，模型与外部服务费用另计。使用前需完成项目配置与模型认证；运行环境要求 Node.js 24+，许可证为 FSL-1.1-ALv2。详见[快速开始](https://vostride.com/docs/agent-qa/quickstart)、[MCP](https://vostride.com/docs/agent-qa/mcp)、[持久记忆](https://vostride.com/docs/agent-qa/memory)与[自我改进](https://vostride.com/docs/agent-qa/self-improvement)文档。
